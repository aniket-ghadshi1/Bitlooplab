# Bitloop Lab — Website

Company website for **Bitloop Lab**: Android app and website development.

## Pages

| Page | File |
| --- | --- |
| Home | `index.html` |
| Services | `services.html` |
| Work (filterable portfolio) | `apps.html` |
| Contact (project brief form) | `contact.html` |

| AdMob app-ads.txt | `app-ads.txt` |

## Editing content

Everything you need to change regularly lives in **`assets/js/data.js`**:

- `SITE`: business email, phone, location, studio time zone, social links, Google Play developer page
- `APPS`: the apps/projects shown on the Home and Work pages. Each app has a `tone` (its poster colour; the text colour is picked automatically) and gets a unique "loop signature" drawing generated from its name. Add a Play Store link and the tile shows a "Google Play" link; add the app's `privacyPolicy` link (e.g. your sites.google.com page) and it appears on the tile and on the Privacy Policy page.

The header, menu and footer are generated by `assets/js/main.js`, so a nav change happens once for every page.

## How it's built

- Plain HTML, CSS and JavaScript — no build step, so GitHub Pages serves it as-is.
- Design system: `assets/css/style.css` (paper/ink/signal palette; Archivo, Instrument Serif and JetBrains Mono from Google Fonts).
- Motion: [GSAP](https://gsap.com) with ScrollTrigger and Flip, self-hosted in `assets/vendor/` (GSAP standard license). The hero "bit loop" is a hand-written canvas animation in `main.js`.
- Accessible by default: if the visitor prefers reduced motion, or the animation scripts fail to load, every page renders fully static with all content visible.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy on GitHub Pages at bitlooplab.co.in

The `CNAME` file already tells GitHub Pages to serve this site at **https://bitlooplab.co.in**.

### 1. Turn on GitHub Pages

1. Repository → **Settings → Pages**
2. Source: **Deploy from a branch**, pick the branch holding these files and `/ (root)`, then **Save**
3. Under **Custom domain**, confirm `bitlooplab.co.in` is filled in

### 2. Add DNS records at your domain registrar

| Type | Host / Name | Value |
| --- | --- | --- |
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| CNAME | `www` | `aniket-ghadshi1.github.io` |

Optional IPv6 (AAAA, host `@`): `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153`.

Delete any other A, AAAA or CNAME records for `@` and `www` (for example a registrar "parking" page). DNS can take up to 24 hours to update.

### 3. Turn on HTTPS

Once GitHub shows the DNS check as successful, tick **Enforce HTTPS** in Settings → Pages. The certificate can take up to an hour to appear.

### 4. Verify

- https://bitlooplab.co.in loads the site
- https://bitlooplab.co.in/app-ads.txt shows `google.com, pub-4490481718549008, DIRECT, f08c47fec0942fa0`

### 5. Connect AdMob

1. In **Google Play Console**, set your developer **Website** to `https://bitlooplab.co.in` (Store settings → Store listing contact details) on every app that shows ads.
2. In **AdMob → Apps → app-ads.txt**, click **Check for updates**. Verification can take up to 24 hours.

AdMob reads `app-ads.txt` only from the domain root, which is why the custom domain matters: the plain `github.io/Bitlooplab/` address would not work.

### Optional

- Submit `https://bitlooplab.co.in/sitemap.xml` in **Google Search Console** so Google indexes the site faster.
- Recommended: verify the domain in GitHub (Settings → Pages → *Verified domains*) so no one else can point a GitHub Pages site at it.
